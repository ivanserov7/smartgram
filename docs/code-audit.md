## Очистка и навигация

Удалён неиспользуемый старый путь покадровой озвучки (`legacy_voiceover.py`, `gemini_tts.py`, дублирующий `requirements-legacy.txt`) и относящиеся только к нему тесты. Актуальные проверки архивов и dry-run перенесены в отдельные тесты. Текущая полная озвучка Gemini сохранена. Также удалён неиспользуемый прямой загрузчик `source_reader.py`: активный исследователь работает через provider search, а старый загрузчик сохранял риск повторного DNS-разрешения после проверки адреса. Удалены только его устаревшие тесты и демо-обвязка; проверки действующей исследовательской политики сохранены.

README заменён кратким руководством: установка, настройки, карта модулей, правила fallback, resume и проверок. Прежний накопительный текст сохранён как явно обозначенная история разработки, а не актуальный контракт.

## Проверки и пределы

Новые регрессии используют подставные провайдеры; локальная обработка изображений и доступные проверки FFmpeg выполняются настоящими библиотеками. Проверяются пустой поиск, отклонение всех фото, лимит поиска, повторное использование результата, отсутствие повторного API-вызова, происхождение изображения, версии сценария, параллельные команды и остановка серверного задания.

Исходный CI выполнял 70 Python-тестов из 9 вручную перечисленных модулей. Полное обнаружение исходного набора нашло 502 теста и выявило проблемы изоляции окружения и переносимости старых фикстур. В рабочем наборе убраны зависимости тестов от внешних ключей/прокси и исправлены фикстуры без ослабления производственных проверок.

Итоговое число тестов и результат полного прогона указаны в описании PR. Три проверки на исторических локальных медиа требуют файлов, которых нет в Git; их пропуск не подтверждает качество этих конкретных старых видео.

Платные API не вызывались. Поэтому этот аудит не подтверждает баланс, доступ конкретного аккаунта к модели, текущую доступность внешних сервисов или художественное качество нового оплаченного ролика. Принятые тексты, голоса, реальные медиа и серверные данные не менялись.

Изменение системного helper `server_infra/control.py` требует установки проверенной версии в `/usr/local/sbin/smartgram`; обычный deploy его не обновляет. Порядок описан в [SERVER_WORKFLOW.md](../SERVER_WORKFLOW.md). Панель обновляется штатным выпуском после принятия PR.

Основная сводка тарифов биллинга пока не оценивает стоимость GPT Image: usage и отдельная оценка генератора сохранены, но отсутствие подтверждённого тарифа в агрегаторе остаётся явным «нет данных». Это не нулевая стоимость.

Аудит не является доказательством отсутствия всех ошибок. Читатели принятых исторических артефактов сохранены там, где они нужны для resume; удаление истории или массовая смена схем здесь не проводились.
