# Отдельный VPN-прокси для Gemini

Поддержка отключена по умолчанию. Это настройка транспорта Gemini TTS, а не
установленный VPN. Модели, голоса, лимиты, проверки TLS и правила повторов прежние.

## Настройка администратором сервера

1. Получить действующую конфигурацию VPN с разрешённым дополнительным устройством.
   Имени Telegram-бота недостаточно. Конфигурация VLESS/подписка или WireGuard
   содержит секреты: хранить её отдельно от Git, журналов и чата, с доступом только
   служебного пользователя VPN и администратора.
2. Установить совместимый VPN-клиент отдельной службой. Настроить HTTP CONNECT
   inbound только на `127.0.0.1:17890`. Исходящие подключения этой службы должны
   идти через выбранный VPN без прямого fallback. Не менять глобальный маршрут,
   DNS или настройки SSH/сайта. Конкретный конфиг зависит от выданной подписки.
3. Проверить работу прокси, внешний адрес через него, затем доступность Gemini
   из того же окружения, где работает конвейер. Геолокация IP сама по себе не
   доказывает доступность API. Проверка списка моделей также не доказывает работу
   синтеза: окончательная проверка требует минимального TTS-запроса, который может
   быть платным. Не запускать автоматически полный ролик или старый запуск.
4. После готовности службы и штатного ожидания активного задания добавить в
   `/etc/smartgram/production.env`:

   ```dotenv
   GEMINI_HTTP_PROXY=http://127.0.0.1:17890
   ```

   Не помещать сюда VLESS-ссылку или адрес подписки. Публиковать код штатно через
   PR, проверки и deploy/drain согласно `SERVER_WORKFLOW.md`. Не редактировать
   файлы production-релиза. Проверить новую задачу и перезапуск VPN-службы.

Параметр читается из `.env` рядом с кодом; переменная процесса приоритетнее.
В production `.env` связан с `/etc/smartgram/production.env`. Пустое значение
оставляет прежнее поведение HTTPX. При заданном значении используется только
локальный HTTP-прокси: глобальные `HTTP(S)_PROXY` и `NO_PROXY` для этого клиента
игнорируются. Ошибка прокси не вызывает переключение на прямое соединение.
Другие клиенты конвейера этой настройкой не изменяются.

## Откат

После штатного завершения активного задания убрать `GEMINI_HTTP_PROXY` или
оставить пустым (учесть переменную окружения процесса, если она задана).
Это возвращает прежний транспорт, но не устраняет прежнюю региональную ошибку.
Код откатывается штатной командой из `SERVER_WORKFLOW.md`. Остановить VPN-службу
после отключения её использования. Секреты подписки в репозиторий не добавлять.
