# Изолированное сравнение русской озвучки

Эксперимент не меняет настройки рабочего конвейера. Один точный сценарий GPS
находится в `comparison_text.txt`; общий управляющий текст — в
`prompts/comparison_narrator.txt`, промпт проверки — в `prompts/comparison_check.txt`.
SHA-256 UTF-8 текста без завершающего перевода строки:
`31294ae3631e8eabddc47341c8efd012b2af92afc611ee00c644b3850333d401`.
Каждая карточка содержит тот же текст; история других образцов не передаётся.

| Вариант | Модель | Голос | API |
| --- | --- | --- | --- |
| A | gpt-realtime-2.1-mini | marin | Realtime WebSocket |
| B | gpt-realtime-2.1-mini | cedar | Realtime WebSocket |
| C | gpt-realtime-2.1 | marin | Realtime WebSocket |
| D | gpt-realtime-2.1 | cedar | Realtime WebSocket |
| E | gpt-audio-1.5 | alloy | Chat Completions |
| F | gpt-4o-mini-tts | marin | Speech API |
| G | tts-1-hd | onyx | Speech API |
| H | gpt-live-1 | marin | отдельный Live WebSocket |

Для Realtime одинаковые параметры: PCM16LE, 24 кГц, моно, speed=1.0,
reasoning=low, максимум 4096 выходных токенов. Для Chat — system с инструкцией,
user с исходным текстом, WAV, максимум 4096 выходных токенов. Speech использует
WAV и speed=1.0. Поле instructions не передаётся старой tts-1-hd.
Обе старые Speech-модели отмечены как контрольные: объявлено отключение
6 января 2027 года. Победитель не выбирается по цене, имени или автоматически.

Live использует `wss://api.openai.com/v1/live/sessions` без model в query,
`session.start`, затем `session.commentary.append`; PCM16LE/24 кГц задаётся
в `session.audio.format`. Сценарий находится в user-истории и speakable context,
а управляющая инструкция — в `session.instructions`. Отправляется только
локальная тишина по 20 мс, микрофон не открывается. Делегация client не запускает
backend; если модель потребует backend, результат помечается unsupported_workflow.
У Live нет события audio.done. Сеанс закрывается после 2,5 с фактической тишины
в аудиопотоке после речи; пробел между текстовыми событиями не считается тишиной.
Ожидается штатный `session.closed`, конечный usage не суммируется с промежуточным.
Предел сеанса — 90 с; обрыв и отсутствие штатного завершения не означают успех.
Даже штатное закрытие не доказывает дословность: её проверяет независимый ASR.

Оригинальный ответ сохраняется как `provider_response.wav`; `original.wav` —
тот же звук с корректным WAV-заголовком, в исходной частоте. Смена частоты
заголовком не применяется. Если WAV потоковый и длина не известна в заголовке,
размер вычисляется по полученным PCM-кадрам. Обрыв известной длины — ошибка.
Копии для сравнения имеют общий RMS: один линейный коэффициент на образец,
без компрессора, лимитера, изменения скорости и частоты. Общая цель понижается,
если иначе возник бы клиппинг. Измерения RMS/peak и gain записываются отдельно.

Каждое успешно завершённое аудио независимо распознаётся gpt-transcribe,
`languages[]=ru`, без исходного сценария в prompt/keywords. Затем gpt-6-luna/low
сравнивает расшифровку и оригинал. Кеш ASR связан с SHA-256 WAV, моделью и языком;
проверка дополнительно учитывает исходник и промпт. Одна расшифровка не доказывает
ошибку диктора. Проверка текста не оценивает акцент, ударения и интонацию.
Из-за расхождения не запускаются новый TTS, исследование, сценарист или Deepgram.

Лимит эксперимента — $2. До каждого вызова сохраняется денежный резерв; если
usage неполон или исход запроса неизвестен, резерв не освобождается. Известная
оценка заменяет резерв только после ответа. Сумма известных оценок и оставшихся
резервов используется как предохранитель перед следующим запросом, не как счёт.
Планирование предполагает около 40 с на образец и 50 аудиотокенов/с для оценки
порядка величины, но не выдаёт эти допущения за фактический usage.
Ожидаемый расход около $0,65; резервы первых попыток и проверок — $1,56.
Для Realtime/Chat используется ограничение выходных токенов; для Live — времени.
У Speech API нет такого ограничения токенов: это внутренний консервативный
предохранитель, а не настройка лимита расходов аккаунта OpenAI.

Usage, request_id и реальные параметры сохраняются в openai_usage.json.
Тарифы из официальной страницы проверены 1 ноября 2026. Расчёт в `estimate()`
является оценкой; для бинарного Speech-ответа usage может отсутствовать, тогда
точная оценка не выдумывается. Для HD используется число символов; для Live —
конечные usage.seconds, иначе измеренное время сеанса как оценка. Backend —
отдельно; при client без его запуска наблюдаемых запросов backend 0.
Подтверждённые деньги берутся только из Costs API. Агрегат за день нельзя
автоматически объявить расходом этого опыта; неподтверждённая привязка остаётся
неизвестной. Сбой отдельного варианта не заменяется чужим аудио.

SDK-повторы отключены. Транспортная ошибка допускает максимум одну техническую
попытку с отдельным резервом и записью. Авторизация, недоступная модель и квота
автоматически не повторяются. После перезапуска завершённые операции используются
из кеша, а неизвестные и неудачные исходы не запускаются заново.
Папка и случайный порядок слепых меток сохраняются. Указатель
`outputs/voice_model_comparison_latest.json` позволяет обычной команде продолжить
последний опыт; новая папка означает отдельный новый платный опыт.

HTML автономный: включает оригиналы и копии звука, восемь карточек, переключатель
моделей и локальные оценки слушателя. В слепом режиме сведения о модели и цене
скрыты в интерфейсе; это не криптографическое сокрытие от просмотра исходного HTML.
Результаты оценок хранятся в localStorage и выгружаются в JSON по кнопке.
