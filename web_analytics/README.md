# Стоимость на сайте Smartgram

Исходники текущей вкладки аналитики Timeweb используют
публичный JSON `outputs/billing/analytics.json` (revision 3), подготовленный
`billing_sync.py`. Python-конвейер на сервер не переносится.

Цена выбирается по каждой категории: подтверждённое распределение Costs API,
иначе оценка наблюдаемого usage по версионному публичному тарифу. Статусы:
«Факт · распределено», «Оценка», «Факт + оценка», «Нет данных»; неполная
стоимость дополнительно помечается «частично». Факт заменяет оценку своей
категории при следующем пересчёте. Неизвестный тариф/usage не становится нулём.
Видимые поисковые действия не подменяют оплаченные поисковые запросы.

Основной экран содержит ровно три карточки: среднее время генерации,
среднюю стоимость готового ролика и число готовых роликов. Без длинных таблиц,
графиков, выбора API, счётчиков токенов и второстепенных метрик.

`production_summary` строится по уникальным проверенным готовым MP4 за всё время,
включая ролики без даты завершения. Исследования и неудачные попытки отдельно
не считаются роликами. Время берётся только из жизненного цикла соответствующего
готового запуска, а не из длины MP4 и не из суммы параллельных API-вызовов.
Без замера полного запуска показывается прочерк. Стоимость — учтённые расходы
связанных вызовов готовой когорты; источник и неполнота сохраняются. Ролики без
цены не становятся бесплатными в среднем: указано покрытие известной ценой.

Обновление без модельных генераций:

```bash
.venv/bin/python billing_sync.py --offline
.venv/bin/python web_analytics/publish.py
```

Без `--offline` первая команда читает административные Costs/Usage и затем
пересчитывает факт/оценки. Нажатие «Обновить» на сайте перечитывает опубликованный
JSON. Само по себе оно не запускает конвейер и не обращается к платным моделям.
Постоянная передача новых журналов с Mac не настраивалась.

Публикация переносит только модули аналитики, безопасный JSON и HTML, создаёт
новый выпуск из действующего сайта и сохраняет прежний для отката. Аккаунт,
данные заданий, SSH-ключи, страницы остальных разделов и цитата входа сохраняются.

Проверка денежного учёта предыдущей итерации: 101 Python-тест (включая сохранение остатка, офлайн-режим,
источники и безопасную пару отчётов), 33 Node-теста на Ubuntu и 23 проверки
аналитики через настоящий HTTPS-домен в настольном/мобильном браузере.
Один цикл административного чтения Costs/Usage: 5 HTTP-запросов; платных
модельных генераций для этой задачи не запускалось.

Проверка компактного экрана: 107 Python-тестов, 5 регрессий денежного контракта
Node и 23 проверки на настоящем домене (компьютер/телефон, три карточки,
отсутствие таблиц, обновление, замеры, источники стоимости и авторизация).
Эта итерация использует сохранённый биллинг; платные и административные
API-запросы к провайдерам не выполнялись.
